# AI use log and declarations

## The log

One row per piece of help, in the assignment note under "AI use log":

| Date | Tool | Kind | What I asked for | What I used, and where |
|---|---|---|---|---|
| 2026-11-15 | Claude (Claude Code) | feedback | Comments on the structure of my method section | Moved the sampling paragraph ahead of the procedure |

`Kind` is one of:

| Kind | Meaning |
|---|---|
| `explanation` | Had a concept, a method or the task itself explained |
| `brainstorming` | Ideas, angles, counter-arguments |
| `outline` | Help with structure |
| `feedback` | Comments on text the student wrote |
| `language` | Spelling, grammar, wording, or translation of the student's own text |
| `text` | Text written by the tool that appears in the submission |
| `code` | Code written or debugged by the tool |
| `data` | Analysis, tables or figures produced with the tool |
| `image` | Images or diagrams generated by the tool |
| `search` | Finding literature or sources |
| `other` | Anything else, described in the row |

Name the tool as precisely as you can: the product, and the model if it is known. Write "What I used" from the student's side: what ended up in the work, or "nothing" if nothing did.

## The declaration

Use the institution's own form or wording when there is one. Look for it in the assignment text, on the course page, and in the `study_context` file named in `profile.md`. Requirements differ between institutions, faculties and courses, so the student confirms the form with the course before submitting.

When no form is given, draft a short statement for the student to edit:

```markdown
## Use of AI tools

In this work I used the following AI tools:

- **Tool (model and version if known):** what it was used for, in one or two sentences, and where in the work it mattered.

I did not use AI tools for: ...

I have checked the content myself and take full responsibility for it.
```

Build the statement from the log. Group the rows by tool and kind, and leave nothing out. Before writing it, ask the student whether anything is missing from the log, including tools used outside this vault. If the log is empty, the declaration says no AI tools were used, and that has to be true.

Some institutions ask students to keep the conversation logs. If the student's does, remind them to save or export the conversations before the deadline.

## Citing AI

Institutions disagree on whether an AI tool belongs in the reference list. Many treat it as a tool to describe and not a source to cite. Follow the institution's guidance, and check the `study_context` file for pointers.
